# 北千住SSSガイドブックの位置傾向・2025年と2026年の照合（2026-11-04時点）

## 前提
- 私的ガイドブック（2025-11-11）のp.11-12の位置・列・3台並びヒートマップを参照。**ガイド本文/図の転載ではなく集約結果のみ**。
- 2025年9月11日～11月3日：ユーザー提供のスロレポRAW Excel（54日・22,788台日）。Excel原本は公開しない。
- 2026年7月8日～11月3日：スロナビ由来の `data/records.json`（119日・53,608台日）。両者は計測方法と機種構成が違う可能性がある。
- 「3の日」は日付末尾3（2025年6日、2026年12日）、「6/0の日」は末尾6/0（2025年10日、2026年23日）。
- 1台当たりの差枚平均と代理指標A（差枚+1,000枚以上かつ2,000G以上）を観測。**実際の設定6を表さない**。
- 2025年ガイドのマップ色は**報告された出現回数（1～10回）**で、実台平均差枚や設定値と同義ではない。

## 機種変更が重要
- 2026年153-157番：沖ドキ！DUOアンコール → 9月7日からミリオンゴッド‐神々の軌跡‐への入替があった。2025年当時はトリプルクラウン等で機種構成が異なる。
- 青A・青Bも期間中に入替があり、列差の変化を「設定投入方針だけの変化」とは断定できない。
- 703-713は2026年にヴヴヴで継続。ただし大勝ち・大負けの分散が大きい。

## 予測への適用ルール
1. 現時点で2025年の「155番強い」をそのまま再利用しない。台移動・機種変更後を別モデルに分ける。
2. 青A/B、緑C/D、銀側、金601-613は最新機種と直近60日・イベント別で逐次検証。古いマップ色だけで重みを固定しない。
3. 3の日は物理的に隣接する列だけで3台判定し、重複窓を独立とみなさない。今後、取材側の**事前告知**と**翌日答え合わせ**を区別して集める。
4. 取得元が異なる2025/2026の差枚を、そのまま同一測定単位だと仮定しない。A判定・同日平均との差・相対順位で感度検証。
5. 少数日の結果を理由に、設定6確率や将来の期待収支を表示しない。

*このレポートは2025年ガイドと2026年台別実績の探索的照合であり、独立した将来予測バックテストではありません。*
