# 許可を得たデータの取り込み用フォルダ

スロレポ等の公式なダウンロード機能で、利用条件に従い入手した`table_data.xlsx`または`*.csv`をここにアップロードしてください。
ただしこのリポジトリはPublicのためアップロード元データも公開されます。第三者の権利や公開条件を事前に確認してください。

CSVの場合、UTF-8で`日付,台番号,機種,差枚,G数,BB,RB`の列が必要です。
Excelの場合、日付列または各シート名に`2026-10-15`等の年月日が必要です。

GitHub Actionsの`SSS Data Sync and Deploy`がファイルを取り込み、`data/records.json`に統合します。
既存日の同じ台番は新規ファイルの値で更新されます。その他の過去日データは残します。
